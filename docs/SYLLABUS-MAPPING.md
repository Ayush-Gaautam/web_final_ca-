# INT402 syllabus coverage

| Syllabus area | Implementation |
|---|---|
| C# and ASP.NET Core MVC | Controllers, dependency injection, Razor views, model binding |
| Authentication and authorization | ASP.NET Core Identity with Admin, Manager, Staff roles and role-protected writes |
| EF Core and SQL Server | `ApplicationDbContext`, SQL Server provider, repeatable migration, Docker Compose |
| Relational modelling | Normalized dish/ingredient/recipe, attendance, events, actuals, waste entities |
| REST APIs | Authorized GET/POST/PUT/DELETE endpoints under `/api` |
| Validation and constraints | DataAnnotations, unique indexes, range checks, duplicate conflict responses |
| Statistical forecasting | Weighted moving average, weekday adjustment, event adjustment, MAE and MAPE |
| Reporting and UX | Dashboard KPI cards, forecast quality, tablet-friendly responsive operations tables |
| Testing | Focused xUnit forecasting and waste-cost tests |
| Software documentation | README, Postman collection, architecture diagram and migration policy |

No machine learning or unrelated technology is used.
